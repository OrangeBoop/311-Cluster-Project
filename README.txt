The data is locally downloaded via our drive, and is found in a folder called Data, 
Link to the drive - https://drive.google.com/drive/folders/1EKJgwC1RnkgGL09NB3QKFRw5hzQ-GEQf?usp=drive_link

How to run our code: 
Firstly create a folder called "Data", then:
Run Final_Pre_EDA_Table.ipynb
Take the csv file created from it (Uncomment if needed) and put it in Data
Run Eda_Final
Take the csv file created from it (Uncomment if needed) and put it in Data
Download the two geojson files in drive and put it in Data
Now you can run each clustering zip/street files, Enjoy!
